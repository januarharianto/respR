# Validation function for auto_rate

This is an internal function for
[`auto_rate()`](https://januarharianto.github.io/respR/reference/auto_rate.md).
Used to validate inputs

## Usage

``` r
validate_auto_rate(x, by, method)
```

## Arguments

- x:

  data.frame object.

- by:

  string.

- method:

  string.

## Value

a data.frame object of the original data
