# Summarise adjust_rate objects

Summarise adjust_rate objects

# S3 method for class 'adjust_rate'
summary(object, pos = NULL, export = FALSE, ...)

- pos:

  logical. Export summary table as data frame.

- ...:

  Pass additional inputs
