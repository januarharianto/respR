# Obtain rate values at non-overlapping intervals of a dataset

This is an internal function for
[`auto_rate()`](https://januarharianto.github.io/respR/reference/auto_rate.md)

## Usage

``` r
auto_rate_interval(dt, width, by)
```

## Arguments

- dt:

  data.frame object.

- width:

  numeric.

- by:

  string.

## Value

a list object with appended class `auto_rate_interval`
