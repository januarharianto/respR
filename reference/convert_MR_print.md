# Print results of convert_MR

Print results of convert_MR

## Usage

``` r
convert_MR_print(oldrates, newrates, from, to, input_class)
```

## Arguments

- oldrates:

  The original rates

- newrates:

  The converted rates

- from:

  The original unit

- to:

  The converted unit

- input_class:

  Class of the input (numeric, convert_rate, convert_rate.ft)
