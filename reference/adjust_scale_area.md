# Convert between multipliers of the same AREA unit, e.g. mm2 to km2

This is an internal function. Converts units of area. Could be combined
with adjust_scale, but didn't know how....

## Usage

``` r
adjust_scale_area(x, input, output)
```

## Arguments

- x:

  numeric.

- input:

  string.

- output:

  string.

## Value

A numeric.
