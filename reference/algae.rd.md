# Oxygen production respirometry data

Data from a respirometry experiment on algae which shows oxygen
production over time.

## Usage

``` r
algae.rd
```

## Format

A data frame object consisting of 1200 rows (20 h of data),and 2
columns: `$Time` in hours, `$Oxygen` in % air saturation.

## Details

- Dissolved oxygen units: `% Air Saturation`

- Time units: `hours`

- Respirometer volume (L): `0.1`

- Temperature (°C): `12`

- Salinity: `30`
