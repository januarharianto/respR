# Kernel density function

This is an internal function for
[`auto_rate()`](https://januarharianto.github.io/respR/reference/auto_rate.md)

## Usage

``` r
kernel_method(dt, width, top_only = FALSE)
```

## Arguments

- dt:

  data.frame object.

- width:

  numeric.

- top_only:

  logical. Should only top ranked result be returned?

## Value

A list object
