# Perform time-width rolling regression

This is an internal function. Used by
[`auto_rate()`](https://januarharianto.github.io/respR/reference/auto_rate.md).

## Usage

``` r
time_roll(df, width, parallel = FALSE)
```

## Arguments

- df:

  data.frame object.

- width:

  numeric. width in time

## Value

a data.table object
